# 載入與轉換

把已經存在的檔案放進這個 app。做法以後再定，這裡先留目標。

相關：[../phase-1/document.md](../phase-1/document.md)

## 目標

- 可以載入 Markdown 和 PDF。
- PDF 要能轉成 Markdown，再變成一篇文件。
- 轉出來的圖片仍走 `assets/`，不嵌在內文裡。

## 已知的想法

PDF 轉文字曾經考慮 PaddleOCR。那是一種做法，不是現在的決定。掃描檔和本來就有文字層的 PDF 可能要走不同的路，到時再拆。
