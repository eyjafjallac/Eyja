# AI agent

只處理這個 app 裡指定範圍的文件。設計之後再談，這裡先把邊界寫下來。

相關：[../phase-4/graph.md](../phase-4/graph.md)、[../phase-1/document.md](../phase-1/document.md)

## 目標

- agent 可以分析、處理圈出來的筆記和 memo。
- 它碰不到範圍以外的東西，也碰不到 app 外面的檔案。
- 模型可以是本機的，也可以是外部 API。
- 這層是 phase 4 的鋪墊：以後由它沿著連結把想法鋪開。

## 已知的疑慮

還不知道本機模型要多大才夠管理這個 app。範圍怎麼圈（一篇、一個標籤、還是手動多選）也還沒定。不在這份檔案裡先設計 agent 的工具或提示。
