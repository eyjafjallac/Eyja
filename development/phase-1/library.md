# 主頁與整理

文件的總系統。外觀放在這一期的最後，先讓找得到、分得了類、開得了新檔。

相關：[document.md](document.md)、[editor.md](editor.md)、[memo.md](memo.md)

## 共識

- 筆記和 memo 都能加標籤。
- 主頁用來整理這些文件，再從這裡進入編輯器。
- 主頁和編輯器都可以新增文件。
- 主頁要能找到對應的文件。前期的搜尋是索引，不是把所有內文拿出來掃。
- 自訂方塊（時鐘之類）是前期最後一項。功能還沒齊之前不做外觀。

## 先照這個做

關鍵字搜尋用 SQLite FTS5，索引標題和內文。

相似度搜尋若要做，用同一個 SQLite 檔上的 `sqlite-vec`，不另開向量資料庫。它排在主要功能之後。放在前期尾端還是更晚，留在下面。

主頁的自訂方塊是畫面配置，存在一份設定裡，不改文件模型。
