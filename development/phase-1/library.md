# 主頁與整理

文件的總系統。外觀放在這一期的最後，先讓找得到、分得了類、開得了新檔。

相關：[document.md](document.md)、[editor.md](editor.md)、[memo.md](memo.md)、[appearance.md](appearance.md)

## 共識

- 筆記和 memo 都能加標籤。標籤是扁平名稱：全庫「數學」就是同一顆，沒有上下層。分層用資料夾。一篇可以同時貼「數學」和「作業」。
- 一篇文件預設最多 5 個標籤。這個上限在主頁設定裡可以改，不寫死在資料庫結構裡。
- 主頁第一版是一張文件列表，用來確認整理功能能用：看列表、篩選、新增、搜尋、進入編輯器。另外有進入設定的入口。
- 主頁和編輯器都可以新增文件。
- 主頁要能找到對應的文件。關鍵字搜尋用 SQLite FTS5，索引標題和內文。
- 相似度搜尋放在前期功能的尾端，仍屬 phase 1。用同一個 SQLite 檔上的 `sqlite-vec`，不另開向量資料庫。
- 外觀和自訂方塊在 [appearance.md](appearance.md)，等功能做完再決定。
- 主頁有設定。時間軸的間隔和要不要淘汰舊版放在這裡，規則見 [history.md](history.md)。memo 的快捷鍵和保存期限也在這裡，見 [memo.md](memo.md)。標籤上限也在這裡。
