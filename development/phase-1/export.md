# 匯出

一篇文件要能離開這個 app，成為 Markdown 或 PDF。

相關：[editor.md](editor.md)、[document.md](document.md)、[../phase-2/latex.md](../phase-2/latex.md)

## 共識

- 前期可以匯出 `.md` 和 PDF。
- PDF 來自已經渲染好的內容（標題、表格、KaTeX 公式、圖片），不是安裝一套 LaTeX 再編譯。
- 編譯真正的 `.tex`、用它產出投稿級的 PDF，在 [latex.md](../phase-2/latex.md)。

## 先照這個做

匯出 Markdown 時，內文裡的 `asset:` 改寫成相對路徑，並把用到的圖片複製到旁邊的資料夾。這樣換一台電腦打開 `.md` 圖還在。

PDF 用同一套渲染結果列印成檔，公式、表格和程式碼區塊不用另寫一次。
